🔄 Continuous Integration (CI)

Continuous Integration allows developers to frequently integrate their code into a shared repository. Every change can be automatically tested to identify errors early.

CI Process

  1. Developer modifies the source code.
  2. Changes are committed using Git.
  3. The code is pushed to GitHub.
  4. GitHub Actions starts the workflow.
  5. Automated tests are executed.
  6. The workflow reports whether the tests passed or failed.

🚀 Continuous Deployment (CD)

Continuous Deployment automatically publishes successfully tested code to the deployment environment.

CD Process

  1. CI tests complete successfully.
  2. The website is prepared for deployment.
  3. GitHub Pages receives the updated website.
  4. The new version becomes publicly available.

⚙️ GitHub Actions

GitHub Actions is used to automate the CI/CD workflow. A workflow file defines the steps that GitHub should execute whenever changes are pushed to the repository.

Instructable: GitHub Actions & GitHub Pages

This guide explains how to develop, test, and automatically deploy a static website using GitHub, GitHub Actions, and GitHub Pages.

1

Create the Project

Create a project folder containing the website files. 

static-web-demo/
│
├── index.html
├── style.css
└── .github/
    └── workflows/
        └── deploy.yml
2

Initialize Git

Open a terminal inside the project directory and initialize a Git repository. 

git init
git add .
git commit -m "Initial website"
3

Create a GitHub Repository

Create a new repository on GitHub and connect your local project to the remote repository. 

git remote add origin YOUR_REPOSITORY_URL
git branch -M main
git push -u origin main
4

Set Up Automated Testing

Automated tests verify that the website contains the required files and that the project structure is valid. 

npm test

Expected result:

✓ All website static checks passed successfully!
5

Create GitHub Actions Workflow

Create the workflow file inside: 

.github/workflows/deploy.yml

The workflow automatically runs whenever changes are pushed to the main branch.

6

Push Changes

After modifying the website, commit and push the changes. 

git add .
git commit -m "Update website"
git push
7

GitHub Actions Executes

GitHub automatically starts the workflow and performs the configured testing and deployment steps.

✓ Checkout Repository
✓ Install Dependencies
✓ Run Tests
✓ Build Website
✓ Deploy to GitHub Pages
8

Access the Deployed Website

Once the workflow completes successfully, the website becomes available through GitHub Pages.

✓ Deployment successful!

🎯 Final Result

Every time code is pushed to GitHub, the project can be tested automatically and the latest version can be deployed without manually uploading the website.

Developer → Git → GitHub → GitHub Actions → Test → Deploy → Website
